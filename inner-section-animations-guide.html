Advanced Inner-Section Animations

Bring your page builder sections to life with scroll-triggered animations and parallax effects

Overview

This system adds professional scroll-triggered animations to inner-section components in your page builder. When users scroll down the page, sections and their columns animate into view with customizable effects.

Key Features

  • Scroll-Triggered: Animations trigger automatically when sections enter the viewport
  • Column Staggering: Animate columns sequentially for a professional cascading effect
  • Parallax Scrolling: Background images move at different speeds for depth
  • Fully Customizable: Control duration, delay, easing, and more
  • No Code Required: Configure everything via the properties panel
  • Loop Options: Choose to play once or repeat on every view

How to Use

Step 1: Add Inner-Section Component

  1. Drag "Inner Section" from the Components panel
  2. Drop it onto your page canvas
  3. Configure the number of columns you need

Step 2: Enable Animations

  1. Click on the inner-section to select it
  2. Scroll down in the Properties panel to "Advanced Animations"
  3. Check "Enable Animations"
  4. Choose your animation type from the dropdown

Step 3: Fine-Tune Settings

  1. Adjust Duration slider for speed (0.8s recommended)
  2. Set Stagger Delay for column sequencing (0.15s recommended)
  3. Choose an Easing function (Ease-Out for natural feel)
  4. Enable Loop if you want animations to replay on every scroll

Step 4: Add Parallax (Optional)

  1. Scroll to "Parallax Effect" section
  2. Check "Enable Parallax Scrolling"
  3. Adjust Speed slider (0.5 is a good starting point)
  4. Make sure your section has a background image set

Step 5: Save and Preview

  1. Click the "Save Page" button
  2. Click "Preview" to see animations in action
  3. Scroll up and down to trigger animations

Technical Implementation

Intersection Observer API

Animations use the modern Intersection Observer API for efficient scroll detection:

const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { // Trigger animation when 10% visible element.classList.add('animation-triggered'); } }); }, { threshold: 0.1, rootMargin: '0px 0px -50px 0px' });

CSS Keyframes

Animations are pure CSS for optimal performance:

@keyframes slideInLeft { from { opacity: 0; transform: translateX(-100px); } to { opacity: 1; transform: translateX(0); } }

Parallax Scroll Handler

Background position updates on scroll events:

function handleParallax() { const offset = (window.pageYOffset - elementTop) * speed; element.style.backgroundPositionY = offset + 'px'; }

Best Practices

  • Don't Overdo It: Use animations sparingly for maximum impact
  • Keep Durations Short: 0.5-1 second animations feel snappier
  • Use Stagger Wisely: 0.15-0.2s stagger creates smooth sequencing
  • Test on Mobile: Ensure animations don't slow down mobile devices
  • Parallax for Headers: Hero sections and headers are perfect for parallax
  • Match Your Brand: Choose animation styles that fit your website's tone
