How to Use

1. Access Admin Interface
http://your-domain.com/qr-codes

Login as admin and navigate to "QR Codes" in the sidebar menu

2. Generate QR Code
  • Select a website from the dropdown
  • Enter campaign name (e.g., "Summer Gala 2025")
  • Optionally set a preset donation amount
  • Choose QR code size (300px - 1000px)
  • Click "Generate QR Code"
3. Download & Use
  • Download PNG: Save for printing on flyers, posters, table tents
  • Copy URL: Share the mobile donation link directly
  • Print: Print pre-formatted QR code with campaign info
4. Track Performance

View statistics at the top of the QR Codes page:

  • Total QR scans
  • Total amount raised
  • Completed vs pending donations
  • Average donation amount
  • Performance by campaign
