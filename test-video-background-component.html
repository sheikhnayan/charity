Component Features

Multiple Video Formats

Supports MP4, WebM, and OGG video formats for maximum compatibility across all browsers.

Customizable Overlay

Choose any color and opacity (0-1) for the overlay to ensure perfect text readability.

Flexible Content

Add text, images, or both. Fully customizable with heading, subheading, and CTA button.

Layout Control

Control horizontal (left/center/right) and vertical (top/center/bottom) alignment.

Fully Responsive

Automatically adapts to mobile, tablet, and desktop with optimized font sizes and spacing.

Playback Options

Control autoplay, loop, mute, and video controls to fit your specific needs.

How to Use in Page Builder

  1. Add Component: Drag "Video Background" from Components panel to canvas
  2. Set Video: Enter video URL and select format (MP4 recommended)
  3. Configure Overlay: Choose color and adjust opacity slider for perfect contrast
  4. Add Content: Select content type and enter text/image details
  5. Adjust Layout: Set text alignment and vertical positioning
  6. Fine-tune: Adjust min height, playback options, and colors
  7. Save & Preview: Save your page and preview on different devices

Pro Tips

Video Optimization
  • Compress videos before uploading (aim for under 5MB)
  • Use 15-30 second clips with loop enabled
  • MP4 (H.264) offers best browser compatibility
  • Always enable mute for autoplay (browser requirement)
Design Best Practices
  • Use 0.5-0.6 overlay opacity for balanced visibility
  • Keep text concise and impactful (less is more)
  • Ensure button has clear, action-oriented text
  • Test on mobile devices for responsiveness
Performance Notes
  • Large video files can slow page load times
  • Consider using poster image for slow connections
  • Test video performance on mobile networks
  • Lazy load videos that are below the fold
